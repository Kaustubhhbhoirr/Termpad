# TermPad

TermPad is a VS Code extension that adds a sidebar panel with one-click buttons to send commands directly to the integrated terminal. Stop typing repetitive commands and boost your productivity!

## Features

- **Built-in Buttons**: Quick access to common commands for navigating, clearing the terminal, Git operations, and process management.
- **Custom Buttons**: Add your own custom commands with labels at the bottom of the panel. These are saved persistently across VS Code restarts.
- **Auto-Terminal Creation**: Automatically opens a new terminal if no active terminal exists when you click a command.

## Usage

1. Open the TermPad view from the Activity Bar (look for the terminal icon).
2. Click any button to send its command to the active terminal.
3. Use the "Your Own" section at the bottom to add frequently used custom commands like `npm run build` or `docker compose up`.

## Installation

(Currently in development)
Press `F5` in the extension project directory to run the extension in a new VS Code window.
